Create `src/components/FaqAccordion.astro` that imports and renders all FAQ items as an accessible accordion.

Structure:
```astro
---
import { faqItems } from "../data/faq";
---
```

Template layout:
1. Section wrapper with vertical spacing (`space-y-3`)
2. For each FAQ item (using `.map()` with index):
   - Outer `<div>` with `bg-white rounded-lg border border-brand-divider overflow-hidden` classes
   - `<button>` trigger with these attributes:
     - `class="faq-toggle w-full text-left px-6 py-4 flex items-center justify-between gap-4 font-medium text-brand-text-heading hover:bg-brand-accent/30 transition-colors focus:outline-none focus:ring-2 focus:ring-brand-primary/50 focus:ring-inset"`
     - `aria-expanded="false"`
     - `aria-controls={`faq-panel-${index}`}`
   - Inside button: `<span>{item.question}</span>` + chevron SVG icon
   - Chevron SVG: `<svg class="faq-icon w-5 h-5 shrink-0 text-brand-primary transition-transform duration-200" fill="none" stroke="currentColor" stroke-width="2" viewBox="0 0 24 24"><path stroke-linecap="round" stroke-linejoin="round" d="M19 9l-7 7-7-7" /></svg>`
   - Answer panel `<div>` with:
     - `id={`faq-panel-${index}`}`
     - `class="faq-panel px-6 pb-4 text-brand-text-body leading-relaxed"`
     - `hidden` attribute (collapsed by default)
     - `<p>{item.answer}</p>` inside

3. Client-side `<script>` for toggle behavior:
```javascript
document.querySelectorAll('.faq-toggle').forEach(btn => {
  btn.addEventListener('click', () => {
    const isExpanded = btn.getAttribute('aria-expanded') === 'true';
    btn.setAttribute('aria-expanded', String(!isExpanded));
    const panelId = btn.getAttribute('aria-controls');
    const panel = panelId ? document.getElementById(panelId) : null;
    if (panel) {
      panel.hidden = isExpanded;
    }
    const icon = btn.querySelector('.faq-icon');
    if (icon instanceof HTMLElement) {
      icon.style.transform = isExpanded ? '' : 'rotate(180deg)';
    }
  });
});
```

Key requirements:
- All aria attributes MUST be present (aria-expanded, aria-controls)
- Panels MUST use `hidden` attribute for proper accessibility
- Chevron MUST rotate 180deg when expanded
- Focus ring must be visible on keyboard navigation (focus:ring-2)
- Do NOT use `<details>/<summary>` — use the button + aria pattern for consistent animation control
