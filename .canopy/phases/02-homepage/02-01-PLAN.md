4. Add a client-side `<script>` tag after the section:
```javascript
const days = ["Sunday","Monday","Tuesday","Wednesday","Thursday","Friday","Saturday"];
const today = days[new Date().getDay()];
document.querySelectorAll('.hours-row').forEach(row => {
  if (row instanceof HTMLElement && row.dataset.day === today) {
    row.classList.add('bg-brand-accent/50', 'rounded-lg', 'px-3', '-mx-3');
    const daySpan = row.querySelector('.hours-day');
    if (daySpan) {
      daySpan.classList.add('text-brand-primary', 'font-bold');
    }
    const timeSpan = row.querySelector('.hours-time');
    if (timeSpan) {
      timeSpan.classList.add('text-brand-primary', 'font-semibold');
    }
  }
});
```

5. Add class `hours-day` to the day name span and `hours-time` to the time span so the script can target them.

6. Below the hours card, add a centered note: `text-sm text-brand-text-muted text-center mt-4` — "Hours may vary on holidays. Call to confirm."
