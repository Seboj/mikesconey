    **JavaScript behavior (inside `<script>` tag):**

    1. **Element references:**
       ```javascript
       const lightbox = document.getElementById('lightbox');
       const lightboxImg = document.getElementById('lightbox-img');
       const lightboxCaption = document.getElementById('lightbox-caption');
       const lightboxCounter = document.getElementById('lightbox-counter');
       const closeBtn = document.getElementById('lightbox-close');
       const prevBtn = document.getElementById('lightbox-prev');
       const nextBtn = document.getElementById('lightbox-next');
       const backdrop = document.getElementById('lightbox-backdrop');
       const items = document.querySelectorAll('[data-gallery-item]');
       let currentIndex = 0;
       ```

    2. **Open function:**
       - Set `currentIndex`
       - Read `data-src`, `data-alt`, `data-caption` from items[index]
       - Update lightboxImg src, alt
       - Update lightboxCaption textContent (hide if empty)
       - Update counter text: "3 of 9"
       - Remove `hidden` class from lightbox
       - Set `document.body.style.overflow = 'hidden'`
       - Focus the close button

    3. **Close function:**
       - Add `hidden` class to lightbox
       - Set `document.body.style.overflow = ''`
       - Return focus to `items[currentIndex]`

    4. **Navigate function (direction: -1 or 1):**
       - Calculate new index with wrapping: `(currentIndex + direction + items.length) % items.length`
       - Call open with new index

    5. **Event listeners:**
       - Each `[data-gallery-item]` gets click listener → open(index)
       - closeBtn click → close()
       - backdrop click → close()
       - prevBtn click → navigate(-1)
       - nextBtn click → navigate(1)
       - Document keydown (only when lightbox visible):
         - Escape → close()
         - ArrowLeft → navigate(-1)
         - ArrowRight → navigate(1)
         - Tab/Shift+Tab → trap focus within lightbox (cycle between close, prev, next buttons)

    6. **Touch/swipe support:**
       ```javascript
       let pointerStartX = 0;
       let pointerStartY = 0;

       lightbox.addEventListener('pointerdown', (e) => {
         pointerStartX = e.clientX;
         pointerStartY = e.clientY;
       });

       lightbox.addEventListener('pointerup', (e) => {
         const dx = e.clientX - pointerStartX;
         const dy = e.clientY - pointerStartY;
         // Only trigger if horizontal swipe > 50px and more horizontal than vertical
         if (Math.abs(dx) > 50 && Math.abs(dx) > Math.abs(dy)) {
           if (dx > 0) navigate(-1); // swipe right = previous
           else navigate(1);          // swipe left = next
         }
       });
       ```

    7. **Focus trap:**
       Track focusable elements inside lightbox (close, prev, next buttons). On Tab: if last element is focused, wrap to first. On Shift+Tab: if first element is focused, wrap to last.

    **Transition/animation:** Add `transition-opacity duration-200` to the lightbox container. On open: set opacity from 0 to 100 (use a requestAnimationFrame to trigger after removing hidden). On close: fade out before adding hidden. Keep it subtle and fast.
