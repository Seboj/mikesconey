  <action>
    Create the Astro 5 project from scratch in the current working directory (do NOT create a subdirectory — files go in project root).

    1. Initialize package.json with:
       - name: "mikesconey"
       - scripts: "dev", "build", "preview"
       - Dependencies: astro@^5.18.0

    2. Install dependencies via npm:
       - astro (core)
       - tailwindcss and @tailwindcss/vite (Tailwind CSS 4 via Vite plugin — do NOT use @astrojs/tailwind)
       - @fontsource-variable/outfit (heading font — variable for all weights)
       - @fontsource-variable/inter (body font — variable for all weights)

    3. Create astro.config.mjs:
       ```js
       import { defineConfig } from "astro/config";
       import tailwindcss from "@tailwindcss/vite";

       export default defineConfig({
         vite: {
           plugins: [tailwindcss()],
         },
       });
       ```

    4. Create tsconfig.json extending Astro's strict preset:
       ```json
       { "extends": "astro/tsconfigs/strict" }
       ```

    5. Create public/robots.txt:
       ```
       User-agent: *
       Allow: /
       Sitemap: https://mikesconey.com/sitemap.xml
       ```

    6. Create public/favicon.svg — a simple red circle with "M" in white (brand placeholder):
       ```svg
       <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 32 32">
         <circle cx="16" cy="16" r="16" fill="#B91C1C"/>
         <text x="16" y="22" text-anchor="middle" fill="white" font-size="20" font-family="sans-serif" font-weight="bold">M</text>
       </svg>
       ```

    7. Create .gitignore with standard Astro ignores:
       ```
       node_modules/
       dist/
       .astro/
       .DS_Store
       ```

    CRITICAL: Do NOT install @astrojs/tailwind — it pins to Tailwind v3 and is deprecated. Use @tailwindcss/vite only.
